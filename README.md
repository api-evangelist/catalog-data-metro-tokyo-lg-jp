# Tokyo Metropolitan Open Data (catalog-data-metro-tokyo-lg-jp)

Tokyo Metropolitan Open Data is a regional government open-data portal for Japan running **CKAN**, exposing a standardized catalog API over ~9,675 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/catalog-data-metro-tokyo-lg-jp/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=catalog-data-metro-tokyo-lg-jp-api-evangelist&utm_content=repo)

## Type
- **kind:** government  ·  **software:** CKAN  ·  **version:** 2.11.4

## API
- **Tokyo Metropolitan Open Data CKAN Action API** — base `https://catalog.data.metro.tokyo.lg.jp/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://catalog.data.metro.tokyo.lg.jp)
- Live endpoint verified: `https://catalog.data.metro.tokyo.lg.jp/api/3/action/status_show` · ~9,675 datasets
